# 🌾 AGRI-ASSIST  
### Smart Crop Advisory System for Farmers

AGRI-ASSIST is an AI-powered web application that helps farmers make data-driven agricultural decisions.  
It provides crop recommendations, soil guidance, weather-based alerts, fertilizer suggestions, and AI-powered disease detection.

---

## 🚀 Features

- 🌱 Crop Recommendation based on soil & climate
- 🧪 Soil Guidance System
- 🌦 Weather-Based Alerts
- 🧴 Fertilizer Recommendation
- 🐛 Image-Based Disease Detection
- 🤖 AI-powered advisory workflows
- 📱 Responsive & farmer-friendly UI
